# 可编辑个人主页 Vue 版

这是一个纯前端 Vue + Vite 项目，无数据库、无后端请求。

## 功能

- 编辑姓名、身份、邮箱、电话、签名和简介
- 点击头像更换本地图片
- 添加文字模块
- 上传图片模块并填写说明
- 内容模块支持上移、下移、删除
- 自动保存到浏览器 localStorage
- 支持编辑/预览切换
- 响应式适配桌面和手机

## 运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址，例如：

```text
http://localhost:5173/
```

## 打包

```bash
npm run build
```

打包后的静态文件在 `dist/` 目录。
